================MATRIXLOG================

MatrixLog är ett enkelt loggningsprogram utvecklat främst för QSO inom skandinavien på 27 MHz och 69 MHz, men det går att logga mer än så, tex DX.
Man kan köra programmet i Mörkt läge eller Ljust läge. Jag rekommenderar Mörkt läge då det är där programmet ska fungera 100%.

Om du har MatrixLog v1.3 eller äldre, spara din logg och radera programmet manuellt. Installera sedan senaste versionen. 
Från v1.4 och framåt meddelar programmet själv när en ny version finns tillgänglig vid uppstart och vid föfrågan via menyn.
