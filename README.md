================MATRIXLOG================

MatrixLog är ett enkelt loggningsprogram utvecklat främst för QSO inom landet på 27 MHz och 69 MHz, men det går att logga mer än så, tex DX.
Man kan köra programmet i Mörkt läge eller Ljust läge. Jag rekommenderar Mörkt läge då det är där programmet ska fungera 100%.
